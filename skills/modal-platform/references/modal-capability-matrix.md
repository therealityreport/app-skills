## Routing Rules

- Start with `SKILL.md`, then open the current reference file named in this matrix.
- Open `modal-repo-index.md` only after the workload shape is clear.
- Use `modal-doc-refresh.md` whenever exact Modal syntax, CLI names, limits, or behavior may have changed.
- Use repository evidence to select patterns, not to override official Modal docs.
- Keep the main skill compact; expand reference files and templates instead of adding long guidance to `SKILL.md`.
