# Privacy Policy

VINTONE Studio is a local Codex plugin. It does not bundle paid VINTONE assets and does not send files anywhere by itself.

## Local Data

The plugin may process paths, design intent, edit instructions, and export preferences that the user provides in the active Codex session.

Paid VINTONE files, Photoshop documents, pattern files, textures, and other licensed assets remain outside the plugin. The plugin should only reference those assets by path when the user supplies a path.

## Live Editing

Live Photoshop edits are copy-first. The plugin is designed to produce plans and runbooks for copied documents. It does not approve edits to original paid source files.

## Network Use

The W1 shell uses no network services. Future integrations must document any external service before use.
