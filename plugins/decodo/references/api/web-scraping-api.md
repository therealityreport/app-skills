## Use In This Plugin

- Skill owners: `skills/decodo-sdk-api/SKILL.md`, `skills/decodo-mcp-scraping/SKILL.md`
- Reference for universal scraping, output formats, auth, headless rendering, and endpoint examples.

## Endpoint Record Template

Every target-specific reference should record:

- Endpoint path.
- Target name.
- Required auth format.
- Supported output modes.
- Sync vs async behavior.
- Parse/headless options.
- SDK equivalent, if available.

## Guardrails

- Do not assume every target uses the same endpoint version.
- Use SDK/API for raw HTML, JSON pipeline output, CSV/export workflows, or target behavior not verified in MCP.
